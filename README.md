# Draft2Digital — Premium website redesign

A responsive React + Vite concept redesign for Draft2Digital.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Project notes
- Multi-page marketing experience using React Router.
- Shared responsive navigation, footer, CTA, feature and FAQ components.
- Pricing copy reflects official Draft2Digital public information checked during project preparation. Verify it with the official pricing/FAQ pages before production launch.
- Dashboard charts and publishing UI are illustrative mockups, not connected to a live author account.
- Sign-in and registration CTAs point to the official Draft2Digital website. No authentication or publishing workflow has been replaced or simulated.
- Retailer names are presented as examples of distribution destinations; confirm the current supported-channel list with Draft2Digital before publishing.
- Original design direction; not an official Draft2Digital release.
